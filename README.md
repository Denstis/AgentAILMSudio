## ✨ Возможности

### 🔹 Генерация кода
- Интеллектуальная генерация Python-кода через LangChain Agent
- Поддержка ReAct-паттерна (Reason + Act)
- До 50 итераций для решения сложных задач
- Автоматическое исправление ошибок выполнения

### 🔹 Безопасная песочница
- Изолированное выполнение кода с ограничением опасных операций
- Белый список безопасных модулей
- Контроль доступа к файловой системе
- Таймауты для предотвращения зависаний

### 🔹 Управление зависимостями
- Автоматическая установка пакетов через `pip`
- Создание и управление виртуальными окружениями
- Git-операции (clone, pull, status)
- Проверка совместимости версий

### 🔹 Интерактивность
- Диалоговый режим с запросами к пользователю
- Окно прогресса в реальном времени
- Цветное логирование всех событий
- Возможность паузы/отмены выполнения

### 🔹 GUI интерфейс
- Современный тёмный/светлый режим
- Многострочное поле для задач
- Консоль вывода с подсветкой
- История выполненных задач

## 🚀 Быстрый старт

### Шаг 1: Запустите LM Studio
1. Откройте LM Studio
2. Загрузите любую модель (рекомендуется CodeLlama, StarCoder, DeepSeek-Coder)
3. Перейдите в раздел **"Local Server"** (↔️)
4. Нажмите **"Start Server"**
5. Запомните URL (обычно `http://localhost:1234`)

### Шаг 2: Запустите агент
```bash
python Agent10.py
```

### Шаг 3: Настройте подключение
В GUI укажите:
- **LM Studio URL**: `http://localhost:1234/v1`
- **Model name**: имя вашей модели (например, `codellama-7b`)
- **Max iterations**: 10-50 (по умолчанию 10)
- **Timeout**: 300 секунд

### Шаг 4: Введите задачу
Примеры задач:
```
Напиши функцию для расчёта чисел Фибоначчи до n
Создай скрипт для парсинга JSON файла
Реализуй простой калькулятор с GUI
```

### Шаг 5: Запустите выполнение
Нажмите **"▶ Запустить"** и наблюдайте за прогрессом!

## 🛠 Инструменты агента

Агент использует следующие инструменты LangChain:

### 1. `safe_python_repl`
**Описание**: Безопасное выполнение Python-кода  
**Вход**: Строка кода  
**Выход**: Результат выполнения или ошибка  

```python
# Пример использования агентом
code = "print(sum([x**2 for x in range(10)]))"
result = safe_python_repl.run(code)
# Output: 285
```

### 2. `pip_install`
**Описание**: Установка Python-пакетов через pip  
**Вход**: Название пакета (и версия)  
**Выход**: Статус установки  

```python
pip_install.run("requests==2.28.0")
# Output: ✅ Successfully installed requests-2.28.0
```

### 3. `git_operation`
**Описание**: Выполнение Git-команд  
**Вход**: Команда git (clone, pull, status, etc.)  
**Выход**: Результат операции  

```python
git_operation.run("clone https://github.com/user/repo.git")
# Output: ✅ Cloned into ./repo
```

### 4. `venv_manager`
**Описание**: Управление виртуальными окружениями  
**Вход**: Команда (create, activate, info)  
**Выход**: Статус операции  

### 5. `ask_user`
**Описание**: Запрос уточнения у пользователя  
**Вход**: Вопрос и варианты ответов (опционально)  
**Выход**: Ответ пользователя

## ⚙️ Конфигурация

### Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `LM_STUDIO_URL` | URL сервера LM Studio | `http://localhost:1234/v1` |

В GUI можно настроить:
- **Temperature**: Креативность (0.0 - 1.0)
- **Max Tokens**: Лимит токенов ответа
- **Top P**: Ядро выборки
- **Frequency Penalty**: Штраф повторений

## 📝 Логирование

Все события записываются в лог-файл:
```
~/.lm_agent/agent_YYYYMMDD.log
```

### Формат лога
```
[HH:MM:SS] [LEVEL] [Thread] Сообщение
```

### Уровни логирования
- 🔍 **DEBUG**: Детальная отладка
- ℹ️ **INFO**: Основная информация
- ⚠️ **WARNING**: Предупреждения
- ❌ **ERROR**: Ошибки
- 🔥 **CRITICAL**: Критические ошибки

### Цветовая схема (консоль)
- DEBUG: Голубой
- INFO: Зелёный
- WARNING: Жёлтый
- ERROR: Красный
- CRITICAL: Пурпурный

## 🔧 Troubleshooting

### ❌ Ошибка подключения к LM Studio
**Решение**:
1. Проверьте, что сервер запущен в LM Studio
2. Убедитесь в правильности URL (`http://localhost:1234/v1`)
3. Проверьте firewall/антивирус

### ❌ ModuleNotFoundError: No module named 'tkinter'
**Решение** (Linux):
```bash
sudo apt-get install python3-tk
# или
sudo yum install python3-tkinter
```

### ❌ Агент зацикливается
**Решение**:
1. Уменьшите `Max Iterations` до 5-10
2. Используйте более точную формулировку задачи
3. Попробуйте другую модель (CodeLlama лучше для кода)

### ❌ Код не выполняется в песочнице
**Решение**:
1. Проверьте белый список модулей в `SafePythonREPL`
2. Избегайте системных вызовов и доступа к сети
3. Для внешних операций используйте инструменты (`pip_install`, `git_operation`)

### ❌ Невозможно установить пакеты
**Решение**:
1. Запустите от имени администратора/root
2. Используйте `--user` флаг: `pip install --user <package>`
3. Создайте виртуальное окружение
